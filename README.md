## 🎯 Overview

**MNetSpeedMeter** is a lightweight Windows application that displays your network upload and download speeds in real-time. With an elegant floating window, color-coded system tray icon, and comprehensive statistics tracking, it's the perfect tool to keep an eye on your internet connection.

### 🌟 Why MNetSpeedMeter?

- 🎨 **Beautiful UI** - Modern, clean interface that blends with Windows
- ⚡ **Lightning Fast** - Minimal resource usage, updates every second
- 🎮 **Fully Customizable** - Adjust refresh rates, display options, and alerts
- 📊 **Detailed Statistics** - Track your data usage over time
- 🔔 **Smart Alerts** - Get notified when speeds are too slow or too fast
- 🚀 **Always Ready** - Auto-start with Windows, always in system tray
- 💯 **100% Free** - No ads, no subscriptions, completely open source

## 🚀 Installation

### Method 1: Quick Install (Recommended)

1. **Download** `MNetSpeedMeter.exe` from [Releases](../../releases)
2. **Run** the downloaded file
3. **Allow** Windows Defender if prompted (click "More info" → "Run anyway")
4. **Look** for the icon in your system tray (near the clock)
5. **Right-click** the icon to explore features!

### Method 2: Build from Source

```bash
# Prerequisites: Visual Studio 2022, .NET 6.0 SDK

# 1. Clone the repository
git clone https://github.com/myselfmk061/MNetSpeedMeter.git

# 2. Open in Visual Studio
cd MNetSpeedMeter
start MNetSpeedMeter.sln

# 3. Build (Ctrl+Shift+B)
# 4. Run (F5)
